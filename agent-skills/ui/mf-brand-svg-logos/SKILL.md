# SVG brand marks

Use for integration cards, partner marks and product directories. Supplied approved brand assets take precedence over a convenient icon package.

1. Find the official asset or exact current Simple Icons export. Verify the mark's identity and current brand-use guidance; a package license does not remove trademark restrictions.
2. Preserve the SVG viewBox and aspect ratio. Use color variants allowed by the brand and check visibility on the actual surface. Do not redraw, stretch or casually recolor a supplied logo.
3. Import only needed marks. Give meaningful standalone logos an accessible name; hide decorative duplicates when the adjacent text already names the brand.
4. Check light/dark surfaces, small sizes and loading behavior. Keep attribution and source links with the consuming project.

Simple Icons exports change over time. Verify the symbol in the installed package instead of promising that an old example import still exists. Never paste unsanitized arbitrary SVG markup from an untrusted upload into the page.
