# X posts

1. Read the brief and any writing samples the user provides. Identify their sentence length, vocabulary, and level of detail.
2. Use only supplied or verified facts. Do not invent personal experience, metrics, endorsements, or a biography.
3. Lead with the update. Describe what changed and why someone would use it.
4. Write a short draft. Remove hype, generic hooks, and repeated points. Keep technical names exact.
5. Offer alternatives only when requested. Check the requested length and platform limits.
6. Return copy ready to paste. Publish only when the user explicitly asks.
